# 中国本科专业目录探索器（2026）

单文件离线网页，收录 **2026 年中国普通高等学校本科专业目录**，支持从学科门类、专业类、专业属性、学位授予说明、原文关键词、代码前缀、专业薪资范围等多维度筛选。

## 功能

- 883 条本科专业记录，支持按代码、名称、门类、专业类、属性、学位说明等字段筛选与排序
- 查询结果中的每个字段都可点击，继续作为新的搜索条件追加到搜索路径
- 全文搜索、左侧分类搜索、搜索路径标签联动
- 亮色 / 暗色主题切换，默认亮色，偏好本地保存
- 字段注释滑出窗、专业解读与就业说明页（右侧滑出）
- 就业与薪资数据区分“该专业专属数据”和“全国 / 城市整体口径”
- 支持导出当前筛选结果为 CSV

## 数据规模

- 专业目录：**883 条**
- 专业解读与就业扩展数据：**989 条**（覆盖 13 个门类、93 个专业类、883 个专业）

## 使用

直接用浏览器打开 `index.html` 即可，**无需联网、无需构建、无需后端服务**。

## 数据口径说明

- 专业薪资：仅 9 个专业有麦可思全国月收入公开值，页面明确标注“全国口径 · 该专业自身数据”
- 城市与全国整体数据：仅作背景参考，标注“全国整体口径 · 非该专业专属薪资”，不代表该专业薪资
- 专业解读、满意度、就业预警等优先采用官方或权威公开来源，并在页面“来源口径”中保留来源信息

## 文件

- `index.html` — 单文件应用，内嵌全部目录数据与扩展说明数据
- `README.md` — 本说明文件

## 数据来源

- 教育部《2026 年中国本科专业目录》PDF
- 阳光高考、学职平台、麦可思、智联招聘等公开数据（详见页面内“来源口径”字段）

数据仅供查询参考，具体招生与就业信息请以官方发布为准。
